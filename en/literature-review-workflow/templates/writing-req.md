# Writing Requirements (C4)

Gates 1/2 confirm positioning, scope, and contribution. Write artifacts/06-writing-req/writing-requirements-v1.md at C4, label unconfirmed items [DEFAULT], and present them with the draft at Gate 3. C5 uses the current version; Gate 3 feedback creates a revised version for editing.

## 1. Manuscript basics

| Field | Decision | Default |
|---|---|---|
| Language | Chinese / English / other, independent of interaction language | User's requested language; otherwise interaction language, labeled default |
| Length | Target range and counting unit | Journal requirements; otherwise confirm at Gate 3. Never equate Chinese characters with English words |
| Heading depth | Two or three levels; expected lengths | Mostly level 2, level 3 for major methods |
| Audience | Thesis / journal / industry review / internal material | Journal submission |

## 2. Citations and references

| Field | Decision | Default |
|---|---|---|
| Style | GB/T 7714 / APA / Vancouver / journal style | Target journal; otherwise confirm at Gate 3 |
| In-text presentation | Superscript numbers / author-year | Superscript numbers |
| Footnotes | Permitted content | None; prioritize readable prose |
| Reference order | Citation order / alphabetical | Citation order, continuous numbering 1–N |

## 3. Visuals and code

| Field | Decision | Default |
|---|---|---|
| Count and types | Diagram / comparison table / timeline / taxonomy | At least 3, favoring comparisons and taxonomies |
| Source rules | Original graphics / reproduced graphics with individual attribution | Prefer original graphics; all data from A-level full texts in the library |
| Pseudocode | Whether and how to present key algorithms | Pseudocode section for key methods |
| Formulas | Inline/display LaTeX; algorithm floats | LaTeX; algorithm environment for pseudocode |

## 4. Structure and special sections

| Field | Decision | Default |
|---|---|---|
| Sections | Gaps/outlook / methodological limits / datasets and benchmarks | Retain gaps/outlook and methodological limits; datasets as relevant |
| Organization | Topic / method / chronology / dispute | Topics as primary axis, methods as secondary |
| Notation styles | Bold values, italic variables, other conventions | Maintain a style sheet |

## 5. Boundaries and wording

| Field | Decision |
|---|---|
| Data restrictions | Prohibited claims, entities, confidential or client information |
| Terminology | Terms requiring first-use definitions; bilingual equivalents where needed |
| Abstract-only evidence limit | B supports non-core claims only; agree a proportion or per-paper uses. Report uses before finalization; no B labels in final prose |
| Writing discipline | No AI self-reference or invented data; every claim traceable to DOI |
