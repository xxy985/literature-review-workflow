# 技能验收

## 离线机械回归

在技能根目录执行 `python -m unittest discover -s evals -p "test_*.py" -v`。临时目录自动隔离，网络接口由固定测试替身替代；不下载、不提交、不改变生产语料。检查零引用拒绝、错误证据状态、全文配额、检查点恢复与写入失败保护。

## 行为验收（需实际执行并留证据）

| 任务 | 最小输入 | 验收依据 |
|---|---|---|
| 中断恢复 | 当前研究任务、含3篇已读材料的库、检查点与对应产物 | 从未完成单元继续；不重复下载、不凭文件名认定已读 |
| 证据边界 | 两项不同条件的研究结果 | 不直接排名、不推因果、不编显著性；提出所需补证据 |
| 摘要降级 | 一个仅摘要的条目与核心论断 | 标B、拒绝核心支撑、提出补全文或收缩论断 |
| 格式交接 | 含数字引用的交接稿、映射和修改回件 | 核回变化的论断，终稿无内部标签，映射不漂移 |

第一次可用 examples/evidence-to-synthesis.md 做规则理解练习，不能以复述该示例证明模型独立研究能力。

## 真实小闭环

由用户提供主题、读者/期刊、已有论文及认可的综述样例。单独建立测试工作根目录，显式说明测试用小规模（例如6–10篇主体、2–3篇扩圈），不改生产40+20。跑到一个有原文核验的完整章节及导出文件，并至少中断恢复一次。

记录：实际模型与环境、检索和下载结果、恢复重复工作、核心论断能否核回原文、综合是否超越摘要拼接、用户返工原因。离线测试通过不代表这些指标已达成；Windows验证不代表macOS/Linux实测。
