# 阅读与证据提取

输入：核验入库条目、实际全文或摘要。输出：每篇版本化阅读笔记，使用 templates/reading-note.md。

先确认读取对象与 DOI/题名一致，再按研究问题、方法、研究条件、结果、局限提取。数值必须带单位、样本/数据集、对照、评估设置和原文定位；没有则写未报告。数学论文记录命题假设、结论和证明边界，不硬套实验指标。

转换文本的 `<!-- page N -->` 可作为 PDF 页定位；记录 PDF 页与印刷页的差别。表格、公式或扫描页有疑点时回看原 PDF；无法可靠读取则标记未核实，不从残缺解析推断结果。

每篇必须区分：作者报告的事实、作者解释、Agent 推断。为关键结果写“能支持什么”和“不能推出什么”，保留限制与反例。A/B 表示读到的材料类型；偏倚、外部有效性与论断支持强弱另行判断。

完成标准：有来源定位、至少一项可用认识和明确边界，且未核实项可见。完成笔记后再 `check --mark-read <paper_id> --contribution "一句话" --evidence A|B`。标记不是自动精读证明，必须与笔记一致。

建议每次处理3–5篇并保存检查点，继续下一批。阅读发现新维度后更新综合表，而不是等60篇全部读完才开始思考结构。B级笔记仅记录摘要实际报告的内容，不补造实验细节。
