# 成文要求（C4 阶段模板）

> 用途：门1/门2先确认研究定位、范围与文章贡献；C4在这些决定上起草 `artifacts/06-writing-req/成文要求-v1.md`，其他细项随初稿交门3。未拍板项用【默认】显式标注。C5按当前版本起草，门3意见形成新版本并用于修改。

## 一、基本盘

| 字段 | 拍板内容 | 默认值 |
|---|---|---|
| 语言 | （中文 / 英文） | 中文 |
| 篇幅 | （目标字数/词数区间） | 8000–12000 字 |
| 章节粒度 | （到二级 / 三级标题；每节预计长短） | 二级为主，重要方法三级 |
| 读者定位 | （学位答辩 / 期刊投稿 / 行业综述 / 内部材料） | 期刊投稿 |

## 二、引用与文献格式

| 字段 | 拍板内容 | 默认值 |
|---|---|---|
| 引用格式 | （GB/T 7714 / APA / Vancouver / 指定期刊格式） | GB/T 7714 |
| 夹注样式 | （上标数字 [1] / 作者-年份） | 上标数字 |
| 是否脚注 | （允许何种内容走脚注） | 不用脚注，正文干净优先 |
| 参考文献列表 | （按引用顺序 / 按作者字序） | 按引用顺序，编号 1–N 连续 |

## 三、图表与代码

| 字段 | 拍板内容 | 默认值 |
|---|---|---|
| 图表数量与类型 | （示意图 / 数据对比表 / 时间线 / 分类框架图） | ≥3，以对比表和分类框架图为主 |
| 图表来源纪律 | （全部自绘于库内数据 / 允许引用原图（须逐个标出处）） | 自绘为主，数据一律来自库内 A 级全文 |
| 伪代码 | （关键算法是否成节展示，样式） | 关键方法给伪代码节 |
| 公式处理 | （行内 LaTeX / 独立公式环境；是否算法 float） | LaTeX；伪代码用 algorithm 环境 |

## 四、结构与专节

| 字段 | 拍板内容 | 默认值 |
|---|---|---|
| 专节取舍 | （研究空白与展望 / 方法局限 / 数据与基准总览） | 研究空白与展望：保留；方法局限：保留；数据总览：视内容定 |
| 组织轴 | （主题 / 方法 / 时间 / 争议，占比倾向） | 以主题为主轴，方法相补 |
| 是否区分符号风格 | （数据值加粗、变量斜体统一样式） | 需要统一样式Style sheet |

## 五、红线与口径

| 字段 | 拍板内容 |
|---|---|
| 数据红线 | （绝对不可出现的提法 / 主体、涉密、客户名等） |
| 术语表 | （首出现必须给定义的术语清单 / 中英对照要求） |
| 摘要级引用上限 | （B 级文献只支撑非核心论点，占比上限或逐篇列举确认）——终稿不加标记，但成文前需列清单向确认人报数 |
| 写作纪律 | 不自称"AI"；不编数据；每个论断可溯源 paper_id |

## 六、交付形态

| 字段 | 拍板内容 | 默认值 |
|---|---|---|
| 最终格式 | （LaTeX 模板 / Word / Markdown） | LaTeX（模板由确认人提供） |
| 中间稿格式 | | Markdown（版本独立文件 v1/v2/v3） |
| 交付包内容 | | 终稿 + 引用审计报告 + library.tsv 导出 + 人工核对清单 |
